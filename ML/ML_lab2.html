CP corresponds to alpha, which is the penalty applied to the number of leaf nodes in a tree. Generally, the test accuracy first increases and then decreases as CP changes. A smaller CP results in a more complex tree, increasing the risk of overfitting. A larger CP produces a simpler tree, increasing the risk of underfitting.

According to the model results, the best CP values are 0 and 0.010, with the model achieving an accuracy of 0.9474875.

Comparing the accuracy at the best CP with that of KNN, we can see that the decision tree’s highest test accuracy is significantly higher than KNN’s best test accuracy. I attribute this difference to KNN being more sensitive to noisy variables.

best_dt_model <- rpart_model$finalModel

rpart.plot(best_dt_model)

There are 4 internal nodes and 5 terminal nodes.

Each path from the root to a leaf represents a rule.

These rules are as follows:

\(R_1 = \{X \mid \text{Age} < 43, \, \text{Salary} < 90{,}000 \}, \quad \hat{Y}=0\)

\(R_2 = \{X \mid \text{Age} < 43, \, \text{Salary} \geq 90{,}000, \, x_7 < 0.82 \}, \quad \hat{Y}=0\)

\(R_3 = \{X \mid \text{Age} < 43, \, \text{Salary} \geq 90{,}000, \, x_7 \geq 0.82 \}, \quad \hat{Y}=1\)
